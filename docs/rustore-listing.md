# Бункер в RuStore: тексты карточки и порядок публикации

## Основное
- **Название:** Бункер
- **Идентификатор приложения (applicationId):** `ru.bunkerpro.game` (после первой публикации менять нельзя)
- **Категория:** Игры → Карточные / Настольные
- **Цена:** бесплатно, без покупок и рекламы
- **Политика конфиденциальности:** https://24bunkerpro.ru/api/privacy
- **Сайт:** https://24bunkerpro.ru
- **Возрастной рейтинг (предложение):** 12+ (вымышленные катастрофы и выбор, кто покинет бункер; есть чат между игроками). Ответьте на анкету консоли честно: чат между пользователями, без насилия, без азартных игр, без покупок.

## Краткое описание
Онлайн-игра для компании: докажите, что вам место в бункере, и выгоните соперников.

## Полное описание
Катастрофа. Мест в бункере меньше, чем людей. У каждого игрока есть тайное досье: профессия, здоровье, возраст, хобби, черта характера, багаж и секрет. Раскрывайте карты, спорьте, убеждайте и голосуйте, кто покинет бункер навсегда.

Что внутри:
• 4–12 игроков в одной комнате, вход по ссылке или коду
• видеосвязь и чат прямо в игре
• боты с характером, если не хватает людей: они спорят и аргументируют сами
• 72 иллюстрированные карты и 5 карт действия: иммунитет, двойной голос, переголосование, проверка здоровья, обмен профессией
• события раунда, таймер выступления, пауза, итоги партии с эпилогом
• без регистрации, без рекламы, бесплатно

Игра подходит для вечеринок, посиделок с друзьями и дистанционных встреч. Для видеосвязи понадобятся камера и микрофон, но можно играть и без них.

## Как собрать приложение (один раз настроить, потом одна кнопка)

### 1. Создать ключ подписи (один раз, хранить в надёжном месте!)
Без этого ключа обновления приложения выпустить будет нельзя. В PowerShell:

```powershell
keytool -genkeypair -v -keystore bunker-release.keystore -alias bunker -keyalg RSA -keysize 2048 -validity 10000
```
Команда спросит пароль и данные. Пароль запомните, файл `bunker-release.keystore` сохраните в двух местах и **не** кладите в репозиторий.

### 2. Положить секреты в GitHub
Репозиторий → Settings → Secrets and variables → Actions → New repository secret:
- `KEYSTORE_BASE64` — содержимое файла ключа в base64. В PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("bunker-release.keystore")) | Set-Clipboard`
- `KEYSTORE_PASSWORD` — пароль от ключа
- `KEY_ALIAS` — `bunker`
- `KEY_PASSWORD` — пароль ключа (если не задавали отдельный, тот же)

### 3. Запустить сборку
GitHub → Actions → «Android build (RuStore)» → Run workflow. Через несколько минут внизу страницы запуска появятся файлы:
- `bunker-debug-apk` — для проверки на телефоне (ставится вручную)
- `bunker-release` — подписанные APK и AAB для магазина

### 4. Проверить на телефоне
Установите debug APK, зайдите в комнату с ботами, разрешите камеру и микрофон, проверьте видео и переподключение.

### 5. Загрузить в RuStore
Консоль RuStore → Добавить приложение → загрузить release APK → заполнить карточку из этого файла → отправить на модерацию (обычно до 3 дней).

Каждое следующее обновление: увеличить `versionCode` при запуске сборки (2, 3, 4…).
