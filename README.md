# ☣️ БУНКЕР — Браузерная Онлайн Игра на Выживание

Многопользовательская психологическая веб-игра «Бункер» с поддержкой вебкамер (WebRTC), голосования, генерацией катастроф, интерактивными карточками персонажей и текстовым чатом.

---

## 🚀 Быстрый запуск

### 1. Требования
- **Node.js** (v18+)

### 2. Запуск Сервера (Backend)
```bash
cd server
npm run build
npm start
```
Сервер будет доступен на `http://localhost:3001` (Socket.IO + WebRTC signaling).

### 3. Запуск Клиента (Frontend)
```bash
cd client
npm run dev
```
Интерфейс игры будет доступен по адресу `http://localhost:5173` (стандартный порт Vite; в старой версии этого файла ошибочно значился порт 3000).

---

## 🎮 Игровые механики

1. **Генерация Персонажа:** Каждому игроку при старте выдается закрытый набор карт:
   - Профессия
   - Состояние здоровья
   - Биологический пол и возраст (фертильность)
   - Хобби и дополнительные навыки
   - Черта характера / фракция
   - Багаж (предмет с собой)
   - Секретный факт
   - Спецкарта действия (обмен карт, иммунитет, удвоение голоса)

2. **Катастрофы и Бункер:** Автоматическая генерация сценария (Ядерный апокалипсис, Вирус "Омега", Астероид, Восстание ИИ) и характеристик бункера (площадь, вместимость, оснащение).

3. **Веб-камеры и Звук (WebRTC):** Каждый участник передает видео и аудио напрямую другим игрокам в реальном времени. Можно отключать камеру и микрофон.

4. **Голосование и Изгнание:** В каждом раунде игроки открывают по 1 характеристике, аргументируют свою полезность в видеочате, после чего происходит анонимное голосование за изгнание 1 участника.

5. **Финал:** Когда в живых остается ровно столько человек, сколько мест в бункере, игра подводит итог шансов на возрождение человечества (зависит от набора профессий и предметов выживших).
